# Retail Sales Analysis & Business Intelligence Dashboard

An end-to-end data analytics project that explores retail sales data, measures business performance, and presents findings through a Power BI dashboard.

## Project Overview

This project uses the Sample Superstore retail dataset to analyse sales, profitability, orders, customers, product categories, regions, and customer segments. The workflow combines Python for data preparation and exploratory analysis, SQL for structured business queries, and Power BI for interactive reporting.

## Business Questions

- How much sales revenue and profit does the business generate?
- Which product categories generate the highest sales?
- Which regions contribute the most profit?
- Which customer segments contribute to sales?
- How do sales change over time?
- Which products generate the highest profit, and which products make a loss?

## Tools & Technologies

- **Python:** data loading, cleaning, exploratory data analysis, and visualisation
- **Pandas / NumPy:** data manipulation and numerical operations
- **Matplotlib:** exploratory charts
- **SQLite:** local relational database
- **SQL:** aggregations, filtering, grouping, sorting, and customer/product analysis
- **Power BI Desktop:** DAX measures, KPI cards, charts, and interactive slicers
- **Git & GitHub:** version control and project hosting

## Project Workflow

1. **Data exploration:** inspect the dataset structure, columns, data types, descriptive statistics, missing values, and duplicates.
2. **Data cleaning:** standardise column names, remove exact duplicate rows, convert date and numeric columns, and export a cleaned CSV.
3. **Exploratory analysis:** calculate sales by category and segment, profit by region, top products, and overall business KPIs.
4. **Data visualisation:** create charts for category sales, regional profit, customer-segment sales, profitable products, monthly sales, and sales versus profit.
5. **SQL analysis:** load the cleaned data into SQLite and run business queries.
6. **Power BI dashboard:** create DAX measures and interactive report visuals with Region, Category, and Order Date slicers.

## Dashboard Features

The Power BI report is designed to include:

- KPI cards: Total Sales, Total Profit, Total Orders, Total Customers, and Profit Margin
- Monthly Sales Trend
- Sales by Product Category
- Profit by Region
- Sales by Customer Segment
- Interactive slicers for Region, Category, and Order Date

## Data Setup

1. Obtain the Sample Superstore CSV from the dataset's original source. Check the dataset's licence/terms before redistributing the file.
2. Place the source file in the `Dataset` folder with this exact name: `Sample - Superstore.csv`.
3. Keep the source file unchanged; the cleaning script reads it and writes `cleaned_retail_sales.csv` separately.

The cleaning script reads the source CSV using `encoding="cp1252"` to handle the character encoding encountered with this dataset copy.

## Setup & Run

Run these commands from the project root directory in the VS Code terminal.

### 1. Create a virtual environment (recommended)

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Run the Python workflow in order

```bash
python Python/01_data_exploration.py
python Python/02_data_cleaning.py
python Python/03_exploratory_data_analysis.py
python Python/04_data_visualization.py
python Python/05_load_data_into_sql.py
```

The scripts create the cleaned CSV, visualisation PNG files, and SQLite database in their respective folders.

### 4. Run the SQL queries

Open `Dataset/retail_sales.db` with [DB Browser for SQLite](https://sqlitebrowser.org/), open the **Execute SQL** tab, and run the queries from `SQL/retail_analysis.sql`.

### 5. Open the Power BI report

Open `PowerBI/Retail_Sales_Analysis.pbix` in Power BI Desktop. If the report asks for the CSV source path, select the `Dataset/cleaned_retail_sales.csv` file on your computer and refresh the report.

## Key Measures

The Power BI report uses DAX measures such as:

```dax
Total Sales = SUM('cleaned_retail_sales'[Sales])
Total Profit = SUM('cleaned_retail_sales'[Profit])
Total Orders = DISTINCTCOUNT('cleaned_retail_sales'[Order ID])
Total Customers = DISTINCTCOUNT('cleaned_retail_sales'[Customer ID])
Total Quantity = SUM('cleaned_retail_sales'[Quantity])
Profit Margin = DIVIDE([Total Profit], [Total Sales], 0)
```

Format **Profit Margin** as a percentage in Power BI.

## Notes & Limitations

- Confirm that the Region, Category, and Order Date slicers are cleared when reporting full-dataset KPI totals.
- The exact results depend on the dataset version and any data-cleaning changes made locally.
- The project currently focuses on descriptive and diagnostic analysis; it does not make sales forecasts or use machine learning.
- Review missing values and invalid date/numeric conversions after running the cleaning script. Do not assume that converting a column automatically resolves missing or invalid records.
